# Конвейер моделей и анимаций (Meshy → Mixamo → Godot)

Скрипты, которыми собраны `models/*.glb` и `animations/*.glb`. Нужны, когда появятся новые персонажи (сотник, центурион, Безумец…) или новые анимации. Godot эту папку не видит (`tools/.gdignore`).

Нужно: Blender 4.x (`apt install blender python3-numpy`; скрипты запускаются в его Python), для `lowpoly.py` — обычный Python с `trimesh`, `pymeshlab`, `Pillow`. Исходники (GLB из Meshy, FBX из Mixamo) в репозиторий не кладём — они большие; храним у себя.

## Шаги

1. **Упростить модель из Meshy:** `python3 lowpoly.py <папка> <имя> <рост_м> 1800` — берёт `<папка>/src/<имя>.glb`, ставит на землю, масштабирует до роста, упрощает до 1800 треугольников с сохранением UV, текстура 128×128. Для Mixamo выгрузить OBJ + текстуру 512×512 в zip.
2. **Mixamo:** загрузить zip, авториг, скачать анимации **FBX Binary, With Skin, 30 fps** (In Place не обязателен — скрипт сам уберёт дрейф). Длинные одежды Mixamo не риггает → шаг 3.
3. **Риг одежды без Mixamo:** `blender -b -P rig_saint.py -- <любая анимация героя With Skin>.fbx <модель>.obj <out>.blend <report>.json` — скелет героя двигается под суставы модели (по росту, кистям, стопам, голове), ориентации костей не меняются; веса — «тепловые» в Blender на копии сетки со слитыми швами UV.
4. **Модель → GLB:** `blender -b -P export_model.py -- <src.fbx|src.blend> models/<имя>.glb <имя> <рабочая_папка>` — сбрасывает позу, запекает поворот Mixamo, добавляет кость `Root`, текстура 128×128 nearest, ≤ 4 кости на вершину.
5. **Анимации → GLB:** список — `anims.json` (`[папка, файл FBX, имя, loop|once|pose, описание]`), затем `blender -b -P export_anims.py -- <папка с FBX> anims.json animations/ manifest.json` (переменная `ONLY=имя1,имя2` — только эти). Циклы — на месте, без повтора последнего кадра; разовые — перемещение в `Root`.
6. **Проверка:** `verify_glb.py` (суставы GLB совпадают с FBX), `render_anim.py` (кадры анимации на модели в Blender). Таблицу `animations/README.md` пересобрать из `manifest.json`.

## Подводные камни (уже учтены)

- Mixamo отдаёт персонажа в сантиметрах при росте в метрах: FBX импортировать с `global_scale=100`.
- В Godot `:` в именах костей превращается в `_` (`mixamorig_Hips`) — в `mixamo_bone_map.tres` имена уже с `_`.
- glTF без skin Godot импортирует просто узлами (без Skeleton3D) — поэтому в каждом файле анимации есть 1 треугольник `anim_skin`.
- «Тепловые» веса Blender не считаются на сетке, порезанной по швам UV (каждый кусок — отдельный остров), — веса считаем на копии со слитыми вершинами и переносим обратно.
- `lowpoly.py`: pymeshlab пишет в `work_<имя>/lp.obj.mtl` строку `map_Kd dummy.png` — перед `rig_saint.py` заменить на `map_Kd tex.png`, иначе модель выйдет белой.
- Godot не переимпортирует файл, если поменялся только `mixamo_bone_map.tres`: удалить `.godot/imported` или поменять `.import`.
