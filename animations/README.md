# Анимации (Mixamo)

Все анимации — из [Mixamo](https://www.mixamo.com) (Adobe), 30 кадров/с, по одной в файле `.glb`. Список и параметры — ниже; таблицу сгенерировал `tools/models/export_anims.py`.

## Как устроены файлы

- **Скелет Mixamo** (33 кости, `mixamorig:Hips` … `mixamorig:RightToe_End`, у кисти одна цепочка пальца `HandIndex1–4`) + кость **`Root`** в начале координат над `Hips` (её добавили мы, для root motion). Godot при импорте меняет `:` в именах костей на `_` (`mixamorig_Hips`).
- **Ретаргет:** `models/mixamo_bone_map.tres` — готовый `BoneMap` (SkeletonProfileHumanoid ← имена Mixamo, уже с `_`). В `.import` каждого файла: `_subresources={"nodes": {"PATH:Armature/Skeleton3D": {"retarget/bone_map": Resource("res://models/mixamo_bone_map.tres")}}}`. После импорта скелет — `%GeneralSkeleton`, дорожки — `%GeneralSkeleton:Hips` и т. п., любая анимация подходит любой модели. Проверено в Godot 4.7.2: все 5 моделей играют анимации со всех 4 исходных скелетов.
- Анимации сняты с четырёх авториггов Mixamo: **A** — герой, **B** — герой, риг № 2 (анимации «на святого»), **C** — горожанин, **D** — горожанка. Это нормально: ретаргет через BoneMap переносит их на любой скелет.
- В каждом файле есть крошечный меш `anim_skin` (1 треугольник, 1 мм): без него glTF не содержит skin и Godot не соберёт Skeleton3D. Сам меш не нужен — можно выкинуть при импорте или не добавлять в сцену.
- Направление: персонаж смотрит по **+Z** (Godot), «вперёд» в таблице — это +Z.
- **цикл** — на месте (In Place): горизонтальный дрейф таза убран, повтор первого кадра в конце выкинут. «Скорость» — с какой скоростью персонаж шёл в оригинальной записи: чтобы ноги не скользили, `speed_scale = скорость_в_игре / скорость_анимации` (герой в игре ходит 2,2 м/с, бегает 4,6 м/с, в приседе 1,0 м/с).
- **разово** — горизонтальное перемещение таза перенесено в кость `Root` (root motion). Без `root_motion_track` персонаж смещается, как в записи; с `AnimationTree.root_motion_track = "%GeneralSkeleton:Root"` — стоит на месте, а смещение берётся из `get_root_motion_position()`. Вертикаль (присел, упал) осталась в `Hips`.
- **поза** — один кадр (для тел и статичных поз; позу можно запечь в статичный меш).

## Чего нет (можно докачать с Mixamo)

- Святой на коленях бьёт камнем (катсцена «первый святой», §3): готовой анимации нет — можно взять `pray_kneel` и добавить удары правой рукой процедурно (IK), или поискать на Mixamo по словам kneel / hit / punch / stab.
- Распятый сотник: поза на кресте — процедурно (руки в стороны, голова набок).
- Не взяты (дубли или не к месту): Left Strafe (бег боком без пары), Male Locomotion Pose, Pick Up Item ×2 (подбирает на бегу), Run With Sword, Running (1), Running (2), Running Jump ×2 (прыжка в игре нет), Running To Turn, Running Turn 180, Descending Stairs (один шаг), Walking Backwards (1), Walk To Stop, Walk Forward Arc Right, Injured Walk Left Turn, Carrying Turn, Kneeing Soccerball, Walking While Texting, дубли Praying / Standing / Walking / Dying, лёжа на возвышении (Laying Nodding, Stroke Nodding, Stroke Shaking Head, Laying Shaking Head).

## Лицензия

Mixamo — бесплатно, без отчислений, в том числе в коммерческих играх. Нельзя распространять анимации отдельно от игры (как набор ассетов). Подробнее — `models/CREDITS.md`.
