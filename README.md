# Тьма по всей земле

PS1-хоррор от первого лица на Godot 4. Иерусалим, 33 г. н.э.: воскресения не случилось, мёртвые святые встали из гробов, над городом вечная тьма. Ты — солдат римского гарнизона, и тебе надо выбраться из города.

**Играть в браузере:** https://lotick2005.github.io/tma/ (обновляется сама после каждого мержа в `main`)

## Что где лежит

| Файл | Зачем |
|---|---|
| `CLAUDE.md` | Библия игры и правила для Claude Code — главный источник правды |
| `PROMPTS.md` | Пошаговые промпты для Claude Code, этапы 0–10 |
| `docs/architecture.md`, `docs/map.svg` | Эскиз архитектуры Иерусалима ~33 г. и карта маршрута побега |
| `.github/workflows/web.yml` | Автосборка браузерной версии на GitHub Pages |
| `tools/get_godot.sh`, `.godot-version` | Скачивание Godot нужной версии для проверок и сборки |

## Как работать

См. начало `PROMPTS.md`: один раз включить GitHub Pages, дальше этапы по одному через https://claude.ai/code.

Дома: открыть папку в Godot той же версии, что в `.godot-version`, и жать F5.
