# Промпты для Claude Code — по этапам

## Перед стартом (один раз)

Репо `lotick2005/tma` уже готово: правила игры, эскиз архитектуры, каркас проекта Godot и автосборка браузерной версии.

1. **Браузерная версия.** На GitHub в репо `tma`:
   - **Settings → General → Danger Zone → Change visibility → Public.** Бесплатный GitHub Pages работает только с публичными репо;
   - **Settings → Pages → Build and deployment → Source: GitHub Actions.**
   После этого каждый мерж в `main` сам собирает игру и выкладывает на https://lotick2005.github.io/tma/ (через 3–5 минут, прогресс — во вкладке **Actions**).
2. **Claude Code в облаке.** Зайди на https://claude.ai/code, подключи GitHub и дай доступ к репо `tma`.

## Как работать с этапами

1. На claude.ai/code открой новую сессию с репо `tma` и напиши: «Выполни этап N из PROMPTS.md» (или вставь блок этапа целиком). Одна сессия — один этап, так у Claude меньше путаницы в контексте.
2. Claude сам читает `CLAUDE.md`, пишет код, проверяет запуск своим Godot и пушит в свою ветку.
3. Когда он закончил — нажми в сессии **Create PR**, потом на GitHub **Merge**. Можно просто попросить Claude смержить.
4. Через 3–5 минут открой https://lotick2005.github.io/tma/ и поиграй. Первым делом кликни по экрану: без клика браузер не даёт звук и мышь. Если видна старая версия — обнови страницу с очисткой кэша (Ctrl+Shift+R).
5. Этап вышел кривым — попроси Claude откатить. Сломалось что-то конкретное — промпт «Баг» в конце файла. Если в браузере ошибка — нажми F12, открой вкладку Console и скопируй красные строки в промпт.

**Дома с Godot:** склонируй репо, открой его в Godot той же версии, что в `.godot-version`, и жми F5. Пока работает Claude Code, не правь в редакторе те же сцены, иначе изменения затрутся.

## Этап 3 — звуковая система

```

Нельзя: делать вступление, врагов, ангела; менять планировку; трогать workflow и пресет «Web».

```
